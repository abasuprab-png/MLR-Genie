# Google Agents CLI Specification (.agents-cli-spec.md)

## Agent Identity
- **Name**: `mlr-genie`
- **Display Name**: MLR Genie — Pharma, Biotech & MedTech Review Execution Agent
- **Framework**: Google Agent Development Kit (`google-adk`) + Google GenAI SDK (`google-genai >= 2.30.1`)
- **Primary Orchestrator Model**: `gemini-3.8-flash`
- **Specialized Routed Models**:
  - `gemini-4-argon`: Substantive Claim-to-Evidence Verification (Workflow C), Multi-Reviewer Conflict Reconciliation (Workflow F), Approval-Day Label Delta Analysis (Section 6, Priority Inference tier)
  - `gemini-3.8-flash`: Interactive Genie Orchestration, Intake Metadata Mapping, Multimodal PDF 2D Bounding-Box Grounding
  - `gemini-3.5-flash-lite`: 24-Hour Pharmacovigilance Adverse Event Gate (`CV-08`), Fast Candidate Claim Triage, Activity Feed Formatting
  - `gemini-embedding-2`: Multimodal Statement & Reference Library Embeddings (`pgvector`)
  - `gemini-3.5-transcribe`: Verbatim & Smart Time-Coded Audio/Video Transcript Ingestion
  - `antigravity-preview-09-2026`: Managed Agent Sandbox for Isolated Multi-File Package Assembly

## Deployment Target & Data Governance
- **Primary Runtime**: Gemini Enterprise Agent Runtime (Vertex AI) / Google Cloud Run
- **Data Residency & Retention**: Regional Vertex AI endpoints (`us-central1`, `europe-west1`), Customer-Managed Encryption Keys (CMEK via Cloud KMS), VPC Service Controls (VPC-SC), Zero Data Retention (ZDR)
- **Input/Output Security**: Google Cloud Model Armor via Agent Gateway (Indirect Prompt Injection & PHI/ICSR screening)
- **Authoritative Storage**:
  - Relational & Vector State: AlloyDB / Cloud SQL for PostgreSQL (`pgvector`)
  - Immutable Object Storage: Google Cloud Storage (Object Versioning + Bucket Lock)
  - Credentials: Google Cloud Secret Manager
